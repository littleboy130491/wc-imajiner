== Changelog ==

= 1.2.2 - 2026-09-18 =
* Return to checkout after auth now uses WooCommerce's native hidden "redirect" field on the My Account login/register forms, with a referer fallback — covers themes whose forms post to a cleaned URL.

= 1.2.1 - 2026-09-18 =
* Fix return-to-checkout after login/registration: the wci_back_to URL was double-encoded, so auth redirects fell back to My Account.

= 1.2.0 - 2026-09-18 =
* Redirect guests from checkout to My Account login/register, then back to checkout after authentication.

= 1.1.0 - 2026-08-14 =
* Add a default AlgolPlus bulk table footer when the rule message is empty.
* Attach invoice PDFs to customer emails and show a download on My Account orders.
* Add a Simplify option to hide the WooCommerce mobile app promo in admin new-order emails.
* Remove the pay-now URL from the default waiting-for-payment email template.

= 1.0.0 =
* Initial release.
